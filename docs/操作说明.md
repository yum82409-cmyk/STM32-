# 运行与编译

适用于 2026-10-25 复验版。保持解压后的目录结构完整。

## 仿真入口

打开 `Proteus/Dual_Board_Sim.pdsprj`，点击左下角绿色运行按钮。两机实际加载 `fw/A/A.hex`、`fw/B/B.hex`；根目录的同名 HEX 是相同内容的副本。

| 原理图位号 | 芯片引脚 | 操作 |
|---|---|---|
| KEY1 | A.PA5 | 触发一轮 PWM1：4s 上升、2s 下降，运行中再次按下忽略 |
| KEY2 | A.PA6 | PWM2 依次为 0→20→40→60→80→0% |
| KEY3 | A.PA7 | 切换电机正反转 |
| RESET | A.NRST | A 机重新开始，电机、计时和渐变状态复位 |
| PAUSE | B.PA5 | 暂停／恢复 A 机；恢复时还原电机档位 |

Proteus 的 BUTTON 在本机通过点击切换按下与释放；每次有效按下后要再点击释放，下次按下才产生新事件。应点击按钮右上方的红色交互点。

暂停时当前 LED 保持点亮，时间冻结，电机停止，PWM1 输出归零并保留进度。暂停时忽略 A 机调速、换向与新渐变请求。恢复后继续原进度。

## 打开示波器

仿真运行后选择 `调试(D) → 5. Digital Oscilloscope`。A 通道接 A.PA8，观察 PWM1。双击原理图中的仪器图标会打开元件属性。

PWM 频率约 1kHz，可从水平时基 `0.1ms`、A 通道约 `1V/div` 开始调整。游标测周期应约 1ms，50% 附近高电平宽度约 0.5ms。100% 时输出为持续高电平，0% 时为持续低电平。

## 重新编译

两机 Keil 工程位于 `Firmware/A/MDK-ARM/A_Firmware.uvprojx` 和 `Firmware/B/MDK-ARM/B_Firmware.uvprojx`。本机使用 Keil ARM Compiler 5.06 update 5；选择 Rebuild 验证零错误、零警告。

中文目录可能使旧 Keil 工程加载失败，推荐在已安装的 Python 中运行：

```powershell
python tools/build.py
```

如果 Keil 安装位置不同：

```powershell
python tools/build.py --keil "E:\Keil 5\UV4\UV4.exe"
```

脚本在英文临时目录编译，两机都成功后更新根目录与 `fw/` 中的 HEX，日志保存到 `docs/build_logs/`。手动编译时也必须把新 HEX 复制到 `fw/`；只更新 Keil 输出目录不会改变 Proteus 加载的固件。

编译后先停止仿真，再重新运行以加载新固件。源码改变后需重新验收，原有 SHA256SUMS 清单只对应交付时版本。

## 时钟与显示

两机属性：`OSC Frequency=8MHz`、`Clock Scale=Off`、`OSC32 Frequency=32.768kHz`。固件使用 HSI 8MHz，不接外部晶振。A 第一行为中文别名张三，时间显示两位小数；B 第一、二行为 PWM1、PWM2，第三行为中文电机状态。

公开版已重新生成张三字库，并重编译两机固件。真实姓名和原始验收截图保留在本地。

字库脚本使用 Pillow：`python tools/gen_font.py 姓名`，输出到当前项目的 `Firmware/A`、`Firmware/B`。更换姓名后还需修改 A 机 `USER_NAME_GLYPH1/2`，再重新编译；不会自动改变姓名绘制调用。可用 `--output-root` 指定独立输出目录进行核对。公开版本默认别名为张三；修改显示内容后需重新编译。

诊断记录时间已从默认的 0—60s 延长到 0—3600s，便于连续复验。可在调试菜单的配置诊断信息中核对；没有关闭或降低警告类别。
