## 二、编译（从干净状态）

### 方式 1：Keil GUI
1. 双击 `Firmware\A\MDK-ARM\A_Firmware.uvprojx`
2. 菜单 `Project → Rebuild all target files`

## 三、Proteus 仿真操作

### 打开工程
双击 `<PROJECT_ROOT>\Proteus\Dual_Board_Sim.pdsprj`

> ⚠️ 若 Proteus 提示 `A_Machine.hex 找不到`：
> 原理图的固件路径是相对路径 `..\单片机\32单片机\stm32cube project\A_Machine\...`，
> 本项目已在该相对位置建立镜像目录并放置 HEX，正常情况下无需处理。

### 确认仿真参数（重要）
双击 U1（左侧 STM32）→ `Program File` 应指向 `A_Machine.hex`
→ `OSC Frequency` = **8MHz**，`Clock Scale` = **Off**
双击 U2（右侧 STM32）→ `Program File` 应指向 `Machine_B.hex`
→ `OSC Frequency` = **8MHz**，`Clock Scale` = **Off**（若显示 `8 Times` 需改为 `Off`，否则 B 机快 8 倍导致串口失步）

### 运行
点击左下角 **▶ 运行** 按钮。状态栏出现 `ANIMATING: ...` 表示仿真运行中。

## 四、逐项评分点操作与预期现象

### 【基础 1】复位重启
- 操作：点击 U1 附近的复位按键
- 现象：A 机 OLED 清屏重新显示，计时从 `0.00` 开始

### 【基础 2】A 机 OLED 第一行中文姓名
- 现象：A 机 OLED 第一行显示公开版隐私别名“张三”
- 若在非公开环境中更换显示文字：见《设计说明与验收报告》§6

### 【基础 3】第四行 0.01s 精度总时间
- 现象：A 机 OLED 第四行 `时间:S.PP`，百分秒位每 10ms 递增
- 验证方法：连续观察 10 秒，末位数字应快速滚动且 10 秒后整数位 +10

### 【基础 4】四路流水灯
- 现象：D1 → D2 → D3 → D4 每秒依次点亮（单灯左移循环）

### 【基础 5】按键1 → PWM1 自动渐变
- 操作：点击 KEY1 按钮（接 PA5）
- 现象：
  - 4 秒内 PWM1 占空比从 0% 匀速升到 100%
  - 然后 2 秒内从 100% 匀速降回 0%
  - 渐变中再按 KEY1 无效（状态机运行中）

### 【基础 6】示波器验证 PWM1
- 现象：虚拟示波器（Digital Oscilloscope）A 通道显示 **1kHz 方波**
- 波形：按下 KEY1 后占空比线性增大再减小（梯形包络）
- 测量点：A 机 PA8（TIM1_CH1）
- 打开方式：仿真运行后选择 `调试(D) → 5. Digital Oscilloscope`。双击原理图中的小示波器图标会打开元件属性窗口，不是波形面板。

### 【发挥 1】按键2 → PWM2 调节
- 操作：点击 KEY2 按钮（接 PA6）
- 现象：A 机第二行 `占比` 依次变为 `20%` → `40%` → `60%` → `80%` → `0`（≥100% 时电机停止并归零）
- 同时：电机转速随占空比变化

### 【发挥 2】按键3 → 电机正反转
- 操作：点击 KEY3 按钮（接 PA7）
- 现象：A 机第三行在 `状态:正转` / `状态:反转` 间切换，电机转向改变

### 【发挥 3】双机通信 + B 机显示
- 现象（B 机 OLED）：
  - 第一行 `PWM1:NN%` —— 跟随 A 机 PWM1 占空比变化
  - 第二行 `PWM2:NN%` —— 跟随 A 机 PWM2 占空比变化
  - 第三行状态：占总空比 =0 → `电机停止`；`<80%` → `正常运作`；`>=80%` → `速度异常`

### 【发挥 4】一键暂停
- 操作：点击 B 机 PAUSE 按钮（PA5）
- 现象（同时发生）：
  1. A 机电机停转（PWM2 输出 0%，方向脚拉低）
  2. A 机计时**冻结**（第四行数字停止跳动）
  3. A 机流水灯**冻结**（当前 LED 保持点亮，不移动）
  4. B 机第三行显示 `电机停止`
- 再按一次：恢复（PWM2 还原到暂停前的占空比，计时继续）

## 五、串口协议速查

| 方向 | 类型 | 帧内容 |
|---|---|---|
| A→B | 0x01 STATE | `AA 55 01 05 P1H P1L P2H P2L FLAGS CKSUM`（100ms 周期） |
| B→A | 0x02 CTRL | `AA 55 02 01 CMD CKSUM`（CMD: 01=暂停 00=恢复） |

- 波特率 **115200-8-N-1**
- 校验：`CKSUM = TYPE ^ LEN ^ PAYLOAD...`（XOR）
- 占空比单位 **0.1%**，大端，范围 0..1000

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| OLED 无显示 | I2C 上拉缺失 | 原理图需在 PB6/PB7 接 4.7k 上拉到 3.3V |
| B 机数值不动 | 串口未交叉 / 未共地 | 检查 A.PA9→B.PA10、B.PA9→A.PA10、GND 互连 |
| B 机运行过快 | Clock Scale 不一致 | 两机都设为 `Off` |
| 仿真极慢 | Clock Scale 未设 Off 或 CPU Load 高 | 确认 `OSC=8MHz`、`Clock Scale=Off` |
| 姓名显示为方框 | 字库未包含该字 | 用 `py gen_font.py 新姓名` 重新生成并编译 |
