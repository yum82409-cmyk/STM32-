# 实现说明

## 电路和引脚

| A 机引脚 | 功能 |
|---|---|
| PA1—PA4 | D1—D4，从左向右，经 R2—R5 的 330Ω 电阻限流 |
| PA5、PA6、PA7 | KEY1、KEY2、KEY3，低电平有效 |
| PA8 | TIM1_CH1，PWM1 和示波器 A 通道 |
| PB0 | TIM3_CH3，PWM2，接 L293D EN1 |
| PB1、PB2 | L293D IN1、IN2，控制电机方向 |
| PB6、PB7 | OLED 软件 I²C：SCL、SDA |
| PA9、PA10 | USART1 TX、RX，交叉连接 B 机 RX、TX |
| NRST | RESET 独立复位 |

B 机 PA5 为 PAUSE，PA9/PA10 为串口，PB6/PB7 为 OLED。两机共地。Proteus 中左侧 MCU 为 U1、驱动器为 U2、右侧 MCU 为 U3。

## 时基

HSI 8MHz，AHB、APB1、APB2 均不分频。

- TIM1、TIM3：PSC=7、ARR=999，计数频率 1MHz，PWM 频率 1kHz。
- 比较值 0—1000 对应 0—100% 占空比。CCR=1000 大于 ARR=999，形成持续高电平。
- TIM2：PSC=7999、ARR=65535，1kHz 自由运行，不开启更新中断。
- 主循环读取 TIM2 计数器，用无符号 16 位差值处理回绕，并累计成 32 位毫秒时间；每 10ms 更新应用状态。
- 流水灯每 1000ms 轮换；PWM1 上升 4000ms、下降 2000ms。计时、流水灯和渐变共用该时基。

原版按 TIM2 更新中断次数累计时间，在本机出现仿真 10s、显示约 11s 的偏差。自由计数器版本跨回绕运行 60s，显示增量为 60.01s；未用经验系数补偿频率。主循环必须在计数器 65.536s 回绕周期内再次读取，当前显示与通信处理耗时远小于该周期。

## 显示与通信

OLED 使用页寻址和帧缓冲，对比上次发送内容，只更新变化列。SDA 高电平及 ACK 周期切换为输入上拉，低电平恢复开漏输出，保留总线建立和 ACK 交接延时。当前 Proteus 启动及本轮交互过程中无逻辑争用警告。

串口状态帧每 20ms 发送一次，两端使用 64 字节接收环形缓冲和 XOR 校验。

| 方向 | 帧格式 |
|---|---|
| A→B | `AA 55 01 05 P1H P1L P2H P2L FLAGS XOR` |
| B→A | `AA 55 02 01 CMD XOR` |

占空比字段以 0.1% 为单位。B 接收完整帧后更新显示，0% 显示电机停止，0—80% 之间显示正常运作，80% 及以上显示速度异常。显示有串口和刷新延迟，瞬时占空比验收应以输出波形／CCR 寄存器为准。

B 的暂停／恢复请求在未得到 A 状态确认时每 100ms 重发。A 对重复暂停和重复恢复保持幂等；B 在没有待确认命令时跟随 A 的暂停状态，使 A 独立复位后按钮状态重新同步。

## 正式配置

`ACCEPTANCE_DEMO=0`、两机 `DEBUG_DISPLAY=0`。此次所有交互截图来自实际点击按键；正式固件没有自动运行验收序列。

图形编辑与仿真设计必须一致。修改 MCU 属性时使用 Proteus 原生属性窗口并保存，避免只修改压缩包中的 ROOT.DSN 而使 ROOT.CDB 保留旧值。
