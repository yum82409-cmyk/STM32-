# KEY1 与示波器实际操作记录

本轮使用 Windows 原生电脑控制，在已运行的 Dual_Board_Sim 工程上操作，没有修改源码或 HEX。

## 已确认

- 运行仿真时，通过顶部“调试 → 5. Digital Oscilloscope”成功打开独立示波器面板。
- 原理图中小示波器图标的彩色示意图不能作为实测波形证据。
- 调整 Channel A 电压旋钮后，量程读数为 1.14 V/div，水平时基读数为 0.1m。
- 点击 A 机 R8 左侧、连接 PA5 的按钮，独立示波器黄色通道出现脉冲变化，同时 B 机 PWM1 从零变为非零值。
- run2_00.png 至 run2_11.png 是同一次点击后的连续采集。可见 B 机 PWM1 先增大后减小，例如约 28%、51%、80%、93%、36%、13%。
- run2_12_return_zero.png 显示 B 机 PWM1 回到 0%，黄色通道回到水平线。
- scope_panel_open.png 是本轮结束时留在屏幕内的完整仪表面板。

## 验证范围

上述证据证明真实按键可触发 PWM1 变化，并可在独立示波器和 B 机显示中观察到。尚未通过游标测量证明上升恰为 4 秒、下降恰为 2 秒；未核验黄色通道绝对电压、极性及脉宽的准确性。采集时仿真速度低于实际时间，不能用电脑截图间隔替代仿真时间。

本轮没有重新验收暂停恢复、NRST 复位，也未重新确认运行中加载的固件文件路径。不要把本目录等同于整体验收通过。
