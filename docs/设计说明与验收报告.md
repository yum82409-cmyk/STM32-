## 2. 定时器参数计算依据

### 时钟树

```
HSE 晶振 8 MHz
  └─ SYSCLK = HSE 直连（不使用 PLL）        = 8 MHz
       ├─ AHB  = SYSCLK / 1                 = 8 MHz
       ├─ APB1 = HCLK / 1                   = 8 MHz  → TIM2/TIM3 时钟 = 8 MHz
       └─ APB2 = HCLK / 1                   = 8 MHz  → TIM1 时钟   = 8 MHz
FCLK Cortex = 8 MHz,  Flash 等待周期 = 0
```

> 选择 HSE 直连 8MHz 的原因：与 Proteus 中 MCU 属性 `OSC Frequency = 8MHz` 完全对应，
> 定时参数可直接整数计算，且仿真速率贴近真实时间（避免 72MHz 时仿真过慢）。

### TIM1 —— PWM1（示波器波形）

| 参数 | 值 | 计算 |
|---|---|---|
| Prescaler | 7 | 8MHz / (7+1) = **1 MHz** 计数频率 |
| Period (ARR) | 999 | 1MHz / (999+1) = **1 kHz** PWM 频率 |
| 分辨率 | 0.1% | 1001 级 → 占空比 0..1000 对应 0..100.0% |
| Pulse (CCR1) | 动态 | 由渐变状态机写入 |

**验证**：T = 1/(1MHz/1000) = 1 ms，f = **1 kHz**。渐变 0→100% 用 4s，即 4000 级，
每 ms 变化 0.25 级 → 由 `pwm1_ms * 1000 / 4000` 整数运算实现。

### TIM3 —— PWM2（电机调速）

| 参数 | 值 | 计算 |
|---|---|---|
| Prescaler | 7 | 8MHz / (7+1) = **1 MHz** |
| Period (ARR) | 999 | 1MHz / 1000 = **1 kHz** PWM 频率 |
| Pulse (CCR3) | 0 / 200 / 400 / 600 / 800 | 对应占空比 0% / 20% / 40% / 60% / 80% |

**验证**：CCR3 = 占空比% × 10（如 20% → 200）。

### TIM2 —— 系统节拍（10 ms）

| 参数 | 值 | 计算 |
|---|---|---|
| Prescaler | 7999 | 8MHz / (7999+1) = **1 kHz** |
| Period (ARR) | 9 | 1kHz / (9+1) = **100 Hz** → 中断周期 **10 ms** |
| 中断 | TIM2_IRQn，抢占优先级 1 | |

**用途**：
- 按键扫描：每 10ms 采样一次
- 计时基准：每次中断 `g_ms += 10`
- 流水灯：累计 1000ms（1 秒）切换一只 LED
- PWM1 渐变：累计毫秒驱动占空比

**0.01 秒计时精度**：`g_ms` 以 10ms 为步长累加，显示时 `t_cs = g_ms / 10`，
即 **0.01s 分辨率**。显示格式 `秒.百分秒`（如 `12.34`）。

### 按键消抖

| 参数 | 值 | 说明 |
|---|---|---|
| 采样周期 | 10 ms | TIM2 中断内调用 |
| 确认次数 | 2 次 | 连续 2 次电平一致才更新状态 |
| 消抖时间 | **20 ms** | 满足机械按键抖动 5–15ms 的抑制需求 |
| 事件类型 | 按下沿 | 只在「松开→按下」时置事件标志 |

## 3. 串口通信协议

### 物理层

- USART1，**115200-8-N-1**，无硬件流控
- A 机 PA9(TX) → B 机 PA10(RX)；B 机 PA9(TX) → A 机 PA10(RX)；共地
- 接收方式：`HAL_UART_Receive_IT` 单字节中断 + **环形缓冲**（64 字节）

### 帧格式（定长头 + 长度 + 载荷 + XOR 校验）

```
+------+------+------+-----+---------------+-------+
| 0xAA | 0x55 | TYPE | LEN | PAYLOAD[LEN]  | CKSUM |
+------+------+------+-----+---------------+-------+
CKSUM = TYPE ^ LEN ^ PAYLOAD[0] ^ ... ^ PAYLOAD[LEN-1]
```

- 双字节帧头 `0xAA 0x55` 用于帧同步
- 长度域 `LEN` 与类型联合校验，长度不符即丢弃整帧
- 末字节 XOR 校验，校验失败整帧丢弃
- 解析为**状态机**（逐字节喂入），不会因单字节错位而卡死

### 帧类型

**0x01 STATE（A → B，LEN=5）**

| 偏移 | 字段 | 含义 |
|---|---|---|
| 0..1 | P1H P1L | PWM1 占空比，单位 0.1%，大端，范围 0..1000 |
| 2..3 | P2H P2L | PWM2 占空比，单位 0.1%，大端，范围 0..1000 |
| 4 | FLAGS | bit0 = 暂停标志（1=已暂停） |

发送周期：**100 ms**（`TX_PERIOD_MS`）

**0x02 CTRL（B → A，LEN=1）**

| 值 | 含义 |
|---|---|
| 0x01 | 暂停（电机停 + 计时冻结 + 流水灯冻结） |
| 0x00 | 恢复（还原暂停前的 PWM2 占空比） |

### 接收缓冲区无竞争设计

```
中断上下文（HAL_UART_RxCpltCallback）：
    只写 rx_head，缓冲满则丢弃新字节
主循环上下文：
    只读 rx_tail 并推进
```

- 单生产者（中断）/ 单消费者（主循环）模型
- `rx_head` 声明为 `volatile`
- 主循环读取前后不共享其他可变状态，**无临界区、无需关中断**
- 旧实现的 `char b_rx_buf[50]` + `b_rx_flag` + `sscanf` 方案已完全废除（无校验、有竞争）

## 6. 显示别名替换方法

公开版统一使用隐私别名“张三”，点阵已按此生成。仅在非公开环境中更换显示文字：

```bash
cd <PROJECT_ROOT>
py tools\gen_font.py 显示别名
```

脚本会自动：
1. 用 SimHei 生成姓名的 16×16 点阵
2. 重新写入 `Firmware/A/Core/Inc/oled_font.h` 与 `Firmware/B/Core/Inc/oled_font.h`
3. 生成对应 `CN_XXX` 拼音枚举

然后在 `Firmware/A/Core/Src/main.c` 的 `USER CODE BEGIN 2` 区修改姓名绘制：

```c
OLED_PutCN(CN_ZHANG, 0U, 0U);   /* 改成你的姓的枚举名 */
OLED_PutCN(CN_SAN,   16U, 0U);  /* 改成你的名的枚举名 */
```

> 注意：若姓名含生僻字，`gen_font.py` 会自动加入字符集并把枚举名以 `xXXXX`（Unicode 码点）形式命名。

### 关于 .pdsprj 文件的修改方式（重要经验）

DSN 是二进制格式，器件属性块结构为：`<4 字节小端长度 L><属性文本, 共 L 字节>`，
属性文本形如 `{PACKAGE=...}` + 换行 + `{PROGRAM=...}` + 换行 + `{OSC=8MHz}` + 换行 + `{CLOCK_SCALE=Off}`，编码 GBK。

**实测结论**：

- ✅ **等长替换安全**：`{CLOCK_SCALE=8 Times}` → `{CLOCK_SCALE=Off    }`（Off 后补空格补足 7 字符），Proteus 正常打开并解析为 `Off`
- ✅ **同步长度字段安全**：用 `tools/proteus/dsn_edit.py` 改写属性并同步 4 字节长度，Proteus 可正常载入（B 机块 582 → 578 已验证）
- ❌ **不同步长度会崩溃**：只改字符串不改长度，Proteus 启动后无窗口（静默崩溃）

**本项目实际修改**：

1. 用 `tools/proteus/dsn_edit.py` 把 B 机 `CLOCK_SCALE` 从 `8 Times` 统一为 `Off`（双机同速，避免 8 倍速致串口失步）
2. HEX 路径保持原理图原有相对路径，把新编译 HEX 复制到该相对路径下（镜像目录已建好）

## 9. 旧工程问题修正对照

| 旧实现的问题 | 本项目的修正 |
|---|---|
| 姓名使用英文字符串 | 改为 SimHei 16×16 中文点阵，公开版统一显示隐私别名 |
| 界面大量英文（`State: STOP`） | 除数字与 `%` 外全部中文（占比/状态/时间/电机停止…） |
| 按键无消抖（`while(读引脚)` 死等） | 10ms 采样 + 连续 2 次一致确认（20ms 消抖），按下沿事件 |
| 串口无校验（`sscanf` 行协议） | `0xAA 0x55` 帧头 + 长度 + XOR 校验，状态机解析 |
| 共享接收缓冲竞争（ISR 与主循环同写 `b_rx_flag`/`idx`） | 环形缓冲单生产者/单消费者，中断只写 `head` |
| 暂停后输出不符题目 | 暂停 = 电机停（CCR=0 + 方向脚拉低）+ 计时冻结 + 流水灯冻结（保持当前 LED） |
| 定时器参数无计算依据（`Prescaler=80-1`、TIM2 复用冲突） | 全部给出计算过程；TIM2=10ms 节拍、TIM1=PWM1、TIM3=PWM2，**各定时器职责独立不复用** |
| 时钟树混乱（PLL×2 + AHB/2 = 16MHz 奇特配置） | HSE 8MHz 直连 SYSCLK，与 Proteus OSC 属性一致 |
| 中文字库数据损坏（`0.40` 之类非法字节） | 字库由脚本程序化生成，无手工粘贴错误 |
| B 机汉字用横向取模 + 运行时转置（易错） | 点阵在生成期即为 OLED 原生列扫描格式，运行时直接 blit |
